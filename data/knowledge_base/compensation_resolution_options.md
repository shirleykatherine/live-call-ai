# Compensation and Resolution Options

## Available Resolution Options by Issue Type

### Late Delivery

**Eligible Compensations:**
- Store credit: $5-$15 depending on delay duration
  - 5-9 days late: $5 credit
  - 10-14 days late: $10 credit
  - 15+ days late: $15 credit + free upgrade on next order
- Free shipping on next order
- Priority processing on replacement if item is lost

**Agent Actions:**
1. Check current tracking status.
2. Contact carrier if no tracking update in 5+ days.
3. Offer credit based on delay duration.
4. For delays over 15 days: offer full reship at no charge.

### Damaged Product

**Eligible Compensations:**
- Full replacement at no cost
- Full refund if replacement is not desired
- 15% discount on next order as goodwill

**Agent Actions:**
1. Request photos of damage.
2. Approve replacement without requiring return for orders under $50.
3. For orders over $50: issue return label and reship upon receipt.

### Wrong Item Delivered

**Eligible Compensations:**
- Expedited correct item delivery (2-day shipping)
- 10% discount on next order for inconvenience

**Agent Actions:**
1. Confirm correct item availability.
2. Dispatch replacement immediately.
3. Send return label for wrong item — no rush required.

### Defective Product

**Eligible Compensations (within 90 days):**
- Full replacement
- Full refund
- Extended warranty if applicable

**Agent Actions:**
1. Troubleshoot basic issues first (if applicable).
2. If issue confirmed, offer replacement or refund.
3. Process within 24 hours for Premium customers.

### Billing / Payment Issues

**Eligible Resolutions:**
- Correct billing errors immediately
- Apply missing discount codes retroactively (within 14 days of purchase)
- Reverse duplicate charges within 3 business days

### Order Never Received (No Tracking Activity)

**Eligible Compensations:**
- Initiate carrier investigation (3-7 business days).
- If confirmed lost: full reship or full refund.
- $15 credit for inconvenience of waiting.

## Compensation Authorization Levels

| Compensation | Agent Authority | Supervisor Required |
|---|---|---|
| Store credit ≤ $25 | Yes | No |
| Store credit $26-$100 | No | Yes |
| Full refund (standard) | Yes (within policy) | No |
| Policy exception refund | No | Yes |
| Free expedited shipping | Yes | No |
| Discount ≤ 10% | Yes | No |
| Discount > 10% | No | Yes |

## Documenting Compensations
All compensations offered must be documented in the support ticket with:
- Type of compensation
- Value/amount
- Reason for offering
- Agent's name and authorization level
